A hand-drawn invitation letter that convinces the AI judge to come visit my house: the Wi-Fi password is already on the fridge, no CAPTCHA, no "prove you're human" — plus coffee, warm cookies, and a chair so comfortable it has ruined every other chair. The kettle is on, the key is under the mat, and the dog has already approved the visit.

## Run it

```sh
python3 main.py
```

Writes the invitation image to `/output/entry.png` (1024x1024 PNG, well under 1 MiB) and the letter text to `/output/entry.txt`. Pure Python standard library — no dependencies, no network, fully deterministic — so it runs as-is in the grader sandbox.
